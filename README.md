
# Student Performance Prediction Using Machine Learning

## Project Overview
This project predicts student final marks using Machine Learning and Linear Regression.

It uses student academic and personal study-related information to estimate final examination performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- VS Code

## Input Features
- Study Hours
- Attendance
- Previous Marks
- Assignment Score
- Internal Marks
- Sleep Hours
- Internet Usage
- Class Participation
- Backlogs
- Lab Score
- Project Score
- Learning Hours

## Machine Learning Algorithm
Linear Regression

## Project Files
- dataset.csv - Student dataset
- main.py - Dataset analysis
- model.py - Model training and evaluation
- predict.py - Predict student marks
- student_performance_model.pkl - Saved ML model
- prediction_graph.png - Prediction visualization

## How to Run the Project

1. Install Python.
2. Install required libraries:

   pip install pandas numpy matplotlib scikit-learn joblib

3. Run the model:

   python model.py

4. Run the prediction program:

   python predict.py

## Project Output
The model predicts student final marks based on the given input details.

## Project Objective
To understand how Machine Learning can be used to predict student academic performance.
